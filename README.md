# 需求排期台

一个用于项目内需求推进与排期的单页应用。围绕「需求池 → 评审 → 排期 → 开发 → 验收 → 上线」这条主线，
把需求、工时、依赖、截止日放在同一张时间轴上看清楚。

## 功能

- **总览**：需求总数、进行中、本周负荷、逾期四项指标，加需求流转漏斗、本周每日投入、需要关注、即将交付
- **甘特排期**：按天/周/月缩放，拖动时间条改开始日、拖右边缘改时长，依赖用箭头连、里程碑与截止日画竖线
- **日历**：月视图，每天列出落在当天的需求与里程碑
- **看板**：按状态分列，支持拖拽推进，带 WIP 上限与「等前置 / 赶不上截止」标记
- **需求列表**：可排序、多选、批量改状态/负责人/优先级/日期/里程碑
- **容量负荷**：按人按周看投入与产能，标出超载与接近满
- **报表**：吞吐趋势、各阶段平均停留、里程碑进度、已上线需求的周期时间
- **详情抽屉**：描述与验收标准、子任务进度、依赖、参考链接、评论与变更历史
- **设置**：成员与产能、工作日与节假日调休、里程碑、CSV 导入导出、回收站、JSON 备份

## 排期怎么算

- 工时按工作日铺开：`distribute()` 把预估工时按每日产能分配到工作日，自动跳过周末、法定假日与调休
- 依赖优先：有前置需求时，开始日取「前置结束的下一个工作日」
- 自动排期：按截止日 → 优先级 → 依赖拓扑序做贪心资源均衡，避免同一人时间重叠
- 截止风险：`none / unplanned / over / tight / ok` 五档，分别对应没设截止日、没排期、赶不上、刚好卡住、正常

## 技术栈

- Vite 5 + React 18，纯 JSX，不依赖 UI 组件库，图标全部手写 SVG
- 无路由，视图切换是内部状态；⌘K 命令面板，1–7 切换视图
- 存储走适配层：默认浏览器 localStorage；连上本地服务时改为服务端文件，多设备共用一份

## 运行

```bash
npm install

npm run dev      # 开发，http://localhost:5173
npm run check    # SSR 冒烟测试 + 排期/依赖/报表/CSV 算法断言
npm run build    # 构建，产物是内联了 CSS/JS 的单个 dist/index.html
npm run serve    # 构建并启动本地服务（静态页 + 数据接口），http://127.0.0.1:4173
```

## 目录结构

```
src/
  components/     视图与通用组件（Gantt / Kanban / Calendar / TableView / Report / Capacity / SettingsView …）
  lib/
    constants.js  状态、优先级、颜色、默认设置
    calendar.js   工作日历（workdays + holidays，支持调休）
    schedule.js   工时铺开、依赖解析、资源均衡、自动排期、截止风险
    report.js     吞吐、停留时长、周期时间
    storage.js    存储适配层（localStorage / 远程）、CSV 解析与导出
  store.jsx       全局状态与所有写操作
server/index.mjs  本地服务：静态托管 + /api/state 读写 + 每日备份
docs/             本地部署与远程访问说明
scripts/          构建内联、冒烟测试、开机自启安装
```
